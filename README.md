# ⚖️ TIC-TAC-CHEAT: The House Always Wins

🎯

> *"You are X. The House is O. Normal rules apply to you. No rules apply to the House."*

## Basic Details

### Team Name: HIGH ON CHAYA

### Team Members

* Member 1: Sreenanda K - ASIET
* Member 2: Angel Devis - ASIET

### Project Description

A completely rigged game of Tic-Tac-Toe where **you are X and the House is O**.

The goal is simple: **try to win.**

The problem? **You can't.**

The House cheats whenever you get too close to victory. Your marks can mysteriously disappear, the House can take multiple turns, squares can suddenly get condemned, and your innocent X's may even get promoted into O's.

But don't worry — **every crime leaves evidence.**

Collect enough evidence, unlock legal counter-measures, reduce the House's composure, and eventually take the cheating House to the **Grand Courtroom Tribunal**.

Because apparently, Tic-Tac-Toe needed a legal system. ⚖️

### The Problem (that doesn't exist)

People were winning Tic-Tac-Toe too easily.

We decided this was unacceptable.

### The Solution (that nobody asked for)

We created a Tic-Tac-Toe game where the AI is legally allowed to cheat, gaslight the player, manipulate the board, and still somehow claim it followed the Terms & Conditions.

There is no real problem.

There is no real solution.

There is only **the House.** 🏠

## Implementation

### For Software:

# Installation

Clone the repository:

```bash
git clone <your-github-repository-link>
```

Navigate into the project folder:

```bash
cd tic-tac-cheat
```

No additional libraries or dependencies are required.

# Run

Since the project uses vanilla ES6 modules, run it using a local web server.

### Using Python:

```bash
python -m http.server 8000
```

### Using Node / npx:

```bash
npx serve .
```

Then open:

```text
http://localhost:8000
```

and prepare to lose. 💀
